More NumPy: Sorting, Random Numbers, Linear Algebra and More

Why This Topic Matters

In an earlier post, we covered the basics of NumPy, creating arrays, doing maths on them, and filtering with a boolean mask. That covers a lot of everyday use, but NumPy has several more tools that come up constantly in real data work: picking specific items with a list of positions, sorting, finding duplicates, combining arrays, generating random numbers, and some simple matrix maths. In this post, you will learn:

  1. Fancy indexing, and the useful where() function
  2. Sorting, finding unique values, and running totals
  3. Joining and splitting arrays
  4. The difference between a view and a copy
  5. Random numbers, and a little bit of linear algebra
  6. Handling missing values, written as nan

1. Fancy Indexing

Besides slicing with start:stop, NumPy lets you pick out several positions at once, by giving it a list of positions:

import numpy as np

a = np.array([10, 20, 30, 40, 50])

idx = [0, 2, 4]
print(a[idx])    # [10 30 50]

You can also pass a list of True/False values directly, the same idea as the boolean mask from the earlier post, just written out by hand:

print(a[[True, False, True, False, True]])
# [10 30 50]

1.1 where(), Choosing a Value Based on a Condition

arr = np.array([1, 2, 3, 4, 5, 6])

print(np.where(arr > 3, "big", "small"))
# ['small' 'small' 'small' 'big' 'big' 'big']

np.where(condition, if_true, if_false) checks the condition at every position, and picks one of the two values depending on the result. Used with just a condition and no values, it instead tells you where the condition was true:

print(np.where(arr > 3))
# (array([3, 4, 5]),)    , the positions where the value was bigger than 3

2. Finding Specific Values

2.1 argmax() and argmin(), the Position of the Biggest or Smallest Value

marks = np.array([70, 85, 60, 95, 80])

print(np.argmax(marks))    # 3, the position of the highest mark
print(np.argmin(marks))    # 2, the position of the lowest mark

print(marks[np.argmax(marks)])    # 95, the actual highest mark

np.max() gives you the value itself. np.argmax() gives you the position of that value, which is useful when you need to know which student, which row, or which item had the highest score.

2.2 sort() and unique()

x = np.array([3, 1, 4, 1, 5, 9, 2, 6])

print(np.sort(x))
# [1 1 2 3 4 5 6 9]

print(np.unique(x))
# [1 2 3 4 5 6 9]

np.unique() also removes duplicates, similar to turning a list into a set. You can ask it to also count how many times each value appeared:

vals, counts = np.unique(x, return_counts=True)
print(vals)      # [1 2 3 4 5 6 9]
print(counts)    # [2 1 1 1 1 1 1]

Here 1 appeared twice, and every other number appeared once.

2.3 Running Totals with cumsum() and cumprod()

y = np.array([1, 2, 3, 4])

print(np.cumsum(y))     # [1 3 6 10]    , running total
print(np.cumprod(y))    # [1 2 6 24]    , running product

cumsum keeps a running total as it moves through the array, 1, then 1+2, then 1+2+3, and so on.

3. Combining and Splitting Arrays

a1 = np.array([1, 2, 3])
b1 = np.array([4, 5, 6])

print(np.concatenate([a1, b1]))
# [1 2 3 4 5 6]

print(np.vstack([a1, b1]))
# [[1 2 3]
#  [4 5 6]]

print(np.hstack([a1, b1]))
# [1 2 3 4 5 6]

concatenate() joins arrays end to end. vstack() stacks them as new rows, one on top of the other. hstack() joins them side by side.

parts = np.array_split(np.arange(10), 3)
print(parts)
# [array([0, 1, 2, 3]), array([4, 5, 6]), array([7, 8, 9])]

array_split() breaks one array into several smaller pieces, as evenly as possible.

4. View vs Copy

Slicing a NumPy array gives you a view, which shares memory with the original. Calling .copy() gives you a completely separate array.
orig = np.array([1, 2, 3])
view = orig[:]
view[0] = 99

print(orig)    # [99  2  3]   , changed too, since it shares memory!

This is different from a plain Python list, and it catches a lot of people by surprise. A slice of a NumPy array is not a fresh copy, it is a window into the same data. If you need a true, independent copy, say so explicitly:

copy = orig.copy()
copy[0] = -1

print(orig)    # [99  2  3]   , unaffected this time

5. Broadcasting with a 2D Array

The earlier post showed broadcasting with a single number, like arr * 2. It also works between a 2D array and a smaller array, as long as the shapes are compatible:

m = np.array([[1, 2, 3], [4, 5, 6]])

row = np.array([10, 20, 30])
print(m + row)
# [[11 22 33]
#  [14 25 36]]

The 1D array row gets applied to every row of m. This works because its length, 3, matches the number of columns in m.

col = np.array([[100], [200]])
print(m + col)
# [[101 102 103]
#  [204 205 206]]

Here col has one value per row, 2 rows, so it gets applied down every column instead. Broadcasting saves you from writing a loop whenever the shapes line up this way.

6. Random Numbers

np.random.seed(0)      # makes the random numbers repeatable

print(np.random.rand(3))
# [0.5488135  0.71518937 0.60276338]   , 3 random numbers between 0 and 1

print(np.random.randint(1, 10, 5))
# [4 8 4 6 3]   , 5 random whole numbers from 1 up to (not including) 10

np.random.seed() is worth remembering, calling it with the same number before generating random values makes the "random" output repeatable, useful whenever you need to share results that others can reproduce exactly.

7. Flattening an Array: ravel() and flatten()

Sometimes you have a 2D array and you just want all its values back as one flat, 1D array:

m = np.array([[1, 2, 3], [4, 5, 6]])

print(m.flatten())    # [1 2 3 4 5 6]
print(m.ravel())       # [1 2 3 4 5 6]

Both give you the same flat result, but they behave differently underneath, in the same way slicing and .copy() did earlier. .flatten() always gives you a brand new, independent array:

flat_copy = m.flatten()
flat_copy[0] = 99

print(m)
# [[1 2 3]
#  [4 5 6]]    , unchanged

.ravel() gives you a view where possible, sharing memory with the original, so changing it can change the original array too:

flat_view = m.ravel()
flat_view[0] = 99

print(m)
# [[99  2  3]
#  [ 4  5  6]]    , changed!

A simple rule: use .flatten() when you want a safe, independent copy, and .ravel() when you only need a quick, read-only flat view and want to avoid the small extra cost of copying.

8. A Little Linear Algebra

A = np.array([[1, 2], [3, 4]])
B = np.array([[5, 6], [7, 8]])

print(A @ B)
# [[19 22]
#  [43 50]]

@ performs real matrix multiplication between two 2D arrays, not the position-by-position multiplication that * does.

print(np.linalg.inv(A))
# [[-2.   1. ]
#  [ 1.5 -0.5]]

print(np.linalg.det(A))
# -2.0000000000000004

np.linalg.inv() finds the inverse of a matrix, and np.linalg.det() finds its determinant. You do not need to know linear algebra deeply to follow this series, but these two functions come up often enough in machine learning that it helps to recognise them.

9. Handling Missing Values (nan)

Real data is often incomplete. NumPy represents a missing number as np.nan, short for "not a number":

d = np.array([1, 2, np.nan, 4])

print(np.isnan(d))
# [False False  True False]

A normal np.mean() would be confused by a nan in the data. Use the nan-aware versions instead, which simply skip over them:

print(np.nanmean(d))    # 2.3333333333333335

Or replace every nan with a real number of your choosing:

print(np.nan_to_num(d, nan=0))
# [1. 2. 0. 4.]

10. Comparing Whole Arrays

print(np.array([1, 2, 3]) == np.array([1, 5, 3]))
# [ True False  True]    , compared position by position

print(np.array_equal(np.array([1, 2, 3]), np.array([1, 2, 3])))
# True    , one single True/False for the whole array

Plain == gives you a result for every position. np.array_equal() instead answers one simple question: are these two arrays exactly the same, as a whole?

11. Applying Your Own Function to Every Value

def classify(m):
    return "pass" if m >= 50 else "fail"

vclassify = np.vectorize(classify)
print(vclassify(np.array([30, 60, 45, 80])))
# ['fail' 'pass' 'fail' 'pass']

np.vectorize() takes a normal Python function, one built for a single value, and lets you apply it to every value in an array at once, without writing a loop yourself.

12. Checking a Whole Array at Once

print(np.all(np.array([True, True, False])))    # False, not every value is True
print(np.any(np.array([False, False, True])))    # True, at least one value is True

np.all() checks whether every value is true, and np.any() checks whether at least one is. Combined with a condition, this is a quick way to answer questions like "did everyone pass?" or "did anyone fail?"

marks = np.array([85, 92, 78, 65, 90])
print(np.all(marks >= 60))    # True, every student passed

Common Mistakes

MistakeWhat happensFix
Changing a slice and expecting the original array to stay the sameThe original changes too, since a slice is a viewUse .copy() when you need an independent array
Using regular np.mean() on data with missing valuesThe result comes back as nanUse np.nanmean() instead
Using * when you meant real matrix multiplicationYou get position-by-position multiplication insteadUse @, or np.dot(), for matrix multiplication
Forgetting np.random.seed() when results need to be repeatableRandom numbers are different every time the code runsCall np.random.seed(some_number) before generating random values
Changing a .ravel() result and expecting the original to stay the sameThe original array can change too, since .ravel() usually returns a viewUse .flatten() if you need a safe, independent copy

Between this post and the earlier one, you now have a solid, practical toolkit for working with numbers in NumPy. This same toolkit, arrays, boolean masks, and vectorized operations, is exactly what you will see again once we start working with pandas.

Practice Questions

  1. What is the difference between np.max() and np.argmax()?
  2. Why does changing a slice of a NumPy array sometimes change the original array too?
  3. What does np.unique(x, return_counts=True) give you back?
  4. What is the difference between * and @ on two 2D arrays?
  5. Why might np.mean() give you nan as a result, and what would you use instead?
  6. What is the main difference between .flatten() and .ravel()?

Answers

  1. np.max() gives the highest value itself. np.argmax() gives the position of that value inside the array.
  2. A slice is a view, not a separate copy, it shares the same underlying memory as the original array.
  3. The unique values, and how many times each one appeared.
  4. * multiplies position by position. @ performs real matrix multiplication.
  5. If the array contains a missing value (nan), a normal mean becomes nan too. Use np.nanmean(), which skips missing values.
  6. .flatten() always returns a new, independent array. .ravel() returns a view where possible, so changing it can change the original array too.
