Feature Selection

What is Feature Selection?

When we build a Machine Learning model, we use a dataset that has many columns. In ML language, each column (except the target/output column) is called a feature.

But here is the problem — not every column is useful. Some columns help the model predict better. Some columns are just noise and confuse the model. Feature Selection means:

Picking only the important columns and removing the useless ones, before training the model.

Simple Example

Suppose we want to predict the Price of a House. We have this data:

House_Size (sq ft)BedroomsOwner_Favorite_ColorPrice (Lakhs)
10002Blue50
15003Red70
20004Green90
8002Blue45

Look at the column Owner_Favorite_Color. Does the owner's favorite color decide the price of the house? No! It has nothing to do with price. This column is useless for our model.

But House_Size and Bedrooms clearly affect the price — bigger house, more bedrooms, more price.

So a good Feature Selection process would say:

  • Keep: House_Size, Bedrooms
  • Remove: Owner_Favorite_Color

This makes the model simpler, faster, and more accurate, because it is not getting confused by useless information.

There are 3 major types of Feature Selection methods:

  1. Filter Method
  2. Wrapper Method
  3. Embedded Method

In this post, we will start with Filter Method in detail. Wrapper Method and Embedded Method are covered in the sections below (full detail coming in the next posts).

1. Filter Method

Filter Method checks each feature separately, using statistics — it does not involve training any ML model. We just look at each column and ask:

"Does this column have a real relationship with the target column, or not?"

If a feature has a strong relationship with the target, we keep it. If it has almost no relationship, we drop it.

Think of it like a first-round filter — like when a company checks resumes before calling people for an interview. Filter Method quickly removes the useless features before we even build the model. That's why it's fast and simple.

The two most common statistical tests used in Filter Method are:

  1. ANOVA (Analysis of Variance) — used when feature is a Number and target is a Category
  2. Chi-Square Test — used when both feature and target are Categories

Let's understand both, one by one, with simple math and pandas code.

1.1 ANOVA (Analysis of Variance)

When to use it?

Use ANOVA when:

  • Your feature (input column) has numbers — like Age, Salary, Marks
  • Your target (output column) has categories — like Pass/Fail, Yes/No

The Idea (in simple words)

ANOVA checks: "If I split the numeric feature into groups based on the target category, are the group averages very different from each other, or almost the same?"

  • If the group averages are very different → the feature is useful, keep it.
  • If the group averages are almost the same → the feature is useless, drop it.

Small Example

We want to predict if a student Passes or Fails an exam, using Study_Hours as a feature.

StudentStudy_HoursResult
A1Fail
B2Fail
C8Pass
D9Pass

Split Study_Hours by Result:

  • Fail group: 1, 2 → Average = 1.5
  • Pass group: 8, 9 → Average = 8.5

The averages (1.5 vs 8.5) are very far apart. This tells us Study_Hours clearly separates Pass and Fail students. So ANOVA will give this feature a high score — meaning it is important, keep it.

The Formula (simplified)

ANOVA calculates something called the F-value:

F = (Variance BETWEEN groups) / (Variance WITHIN groups)
  • Variance between groups = how different the group averages are from the overall average.
  • Variance within groups = how spread out the values are inside each group.

Simple rule: Bigger F-value = feature is more useful. Smaller F-value (close to 0 or 1) = feature is not useful.

You don't need to calculate this by hand every time — Python does it for us. Let's see how.

Doing ANOVA with Pandas + Sklearn

import pandas as pd
from sklearn.feature_selection import f_classif

# Step 1: Create the dataframe
data = {
    'Study_Hours': [1, 2, 3, 8, 9, 7, 2, 8],
    'Result':      ['Fail', 'Fail', 'Fail', 'Pass', 'Pass', 'Pass', 'Fail', 'Pass']
}
df = pd.DataFrame(data)

# Step 2: Separate feature (X) and target (y)
X = df[['Study_Hours']]   # feature must be numeric
y = df['Result']          # target is category

# Step 3: Apply ANOVA (f_classif)
f_score, p_value = f_classif(X, y)

print("F-score:", f_score)
print("p-value:", p_value)

How to read the result:

  • F-score — higher value means the feature is more useful (as we discussed above).
  • p-value — this tells us if the result is trustworthy.
    • If p-value is less than 0.05 → the feature is important, keep it.
    • If p-value is more than 0.05 → the feature is not important, you can drop it.

In our example, Study_Hours will get a high F-score and a very small p-value, confirming it is a strong feature for predicting Pass/Fail.

1.2 Chi-Square Test (χ²)

When to use it?

Use Chi-Square when:

  • Your feature (input column) is a category — like Gender, City, Color
  • Your target (output column) is also a category — like Yes/No, Pass/Fail

The Idea (in simple words)

Chi-Square checks: "Is there a real connection between two category columns, or are they just showing random, unrelated numbers by chance?"

It compares:

  • Observed values — what we actually see in our data
  • Expected values — what we would see if there was no relationship at all between the feature and target

If Observed and Expected are very different, it means there is a real relationship — keep the feature. If they are almost the same, there is no relationship — drop the feature.

Small Example

We want to check if Gender affects whether a person Buys a Product.

PersonGenderBought_Product
1MaleYes
2MaleYes
3MaleNo
4FemaleNo
5FemaleNo
6FemaleNo

First, make a contingency table (a simple count table):

Bought = YesBought = NoTotal
Male213
Female033
Total246

Expected value formula (if Gender had NO effect on buying):

Expected = (Row Total × Column Total) / Grand Total

For Male & Yes: Expected = (3 × 2) / 6 = 1
But Observed Male & Yes = 2

Since Observed (2) is different from Expected (1), this hints Gender might actually be related to buying behaviour.

The Formula (simplified)

Chi-Square (χ²) = Sum of [ (Observed − Expected)² / Expected ]

We do this calculation for every cell in the table, then add them all up. Bigger Chi-Square value = stronger relationship = keep the feature.

Doing Chi-Square with Pandas + Sklearn

import pandas as pd
from sklearn.feature_selection import chi2
from sklearn.preprocessing import LabelEncoder

# Step 1: Create the dataframe
data = {
    'Gender': ['Male', 'Male', 'Male', 'Female', 'Female', 'Female'],
    'Bought_Product': ['Yes', 'Yes', 'No', 'No', 'No', 'No']
}
df = pd.DataFrame(data)

# Step 2: Convert categories into numbers (Chi-square needs numeric input)
le = LabelEncoder()
df['Gender_encoded'] = le.fit_transform(df['Gender'])   # Male=1, Female=0 (example)
df['Target_encoded'] = le.fit_transform(df['Bought_Product'])

X = df[['Gender_encoded']]
y = df['Target_encoded']

# Step 3: Apply Chi-Square
chi_score, p_value = chi2(X, y)

print("Chi-Square score:", chi_score)
print("p-value:", p_value)

How to read the result:

  • Same rule as before — higher Chi-Square score and p-value < 0.05 means the feature has a real relationship with the target, so keep it.

Quick Recap

TestFeature TypeTarget TypeKeeps feature when...
ANOVANumericCategoryF-score is high, p-value < 0.05
Chi-SquareCategoryCategoryChi-Square score is high, p-value < 0.05

Filter Method is usually the first step in Feature Selection — quick, cheap, and done before any model training.
