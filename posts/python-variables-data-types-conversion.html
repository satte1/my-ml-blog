Variables, Data Types and Type Conversion

What is a Variable?

When we write a Python program, we need a place to keep information — like a person's age, a name, or the price of a product. That place is called a variable.

A variable is just a name that points to a value stored in the computer's memory.

Think of a variable like a name tag on a box. The box holds the value, and the name tag lets you find it again whenever you need it.

Simple Example

age = 25
name = "Satyam"
price = 499.99

print(age)     # 25
print(name)    # Satyam
print(price)   # 499.99

Here age, name and price are variables. The = sign does not mean "equal to" like in maths. It means "store this value in this name".

Notice one more thing: we never told Python what kind of value each variable holds. Python looks at the value and understands it on its own. This is called dynamic typing.

Rules for naming a variable

  • Use only letters, numbers and underscore (_) — for example student_age
  • Do not start the name with a number — 1age is wrong, age1 is fine
  • Do not use spaces — write total_marks, not total marks
  • Names are case-sensitive — Age and age are two different variables

What is a Data Type?

Every value in Python has a data type. The data type tells Python what kind of value it is, and what you are allowed to do with it.

For example, you can multiply two numbers, but it makes no sense to multiply two names. The data type is how Python knows the difference.

There are 4 basic data types that you will use almost every day:

TypeMeaningExample
intWhole numbers (no decimal point)25, -3, 1000
floatDecimal numbers3.14, 499.99
strText (always inside quotes)"Satyam", "Jaipur"
boolOnly two values — Yes or NoTrue, False

How to check the data type?

Use the built-in type() function. It tells you the type of any value or variable.

age = 25
price = 499.99
name = "Satyam"
is_active = True

print(type(age))        # <class 'int'>
print(type(price))      # <class 'float'>
print(type(name))       # <class 'str'>
print(type(is_active))  # <class 'bool'>

Remember: anything inside quotes is a str, even if it looks like a number. So "25" is text, and 25 is a number. This small difference is the reason for the next section.

The Problem: "25" is not the same as 25

Look at these two lines:

a = 25      # int  (a number)
b = "25"    # str  (text)

On the screen they look almost the same. But for Python they are completely different things. See what happens when we use the * sign on both:

print(25 * 3)     # 75
print("25" * 3)   # 252525

The number 25 gets multiplied, so we get 75. The text "25" just gets repeated three times, so we get 252525. Same look, very different result!

The Error Every Beginner Sees

Now let's try to add a number to a piece of text:

age = "25"
print(age + 5)

Python gives an error:

TypeError: can only concatenate str (not "int") to str

Why? Python does not know what you want. Should it add the numbers (25 + 5 = 30)? Or join the texts ("25" + "5" = "255")? Since it cannot decide, it stops and shows an error.

This happens very often in real work, because data coming from a form, a file, or the input() function almost always arrives as str, even when it looks like a number.

The solution is Type Conversion.

Type Conversion

Type Conversion (also called Type Casting) means:

Changing a value from one data type to another data type.

There are 2 kinds of type conversion:

  1. Implicit Conversion — Python does it automatically
  2. Explicit Conversion — you do it yourself

1. Implicit Conversion (automatic)

What is it?

Sometimes Python changes the type for you, without being asked. It does this only when it is safe and no information will be lost.

Small Example

x = 5        # int
y = 2.5      # float

result = x + y
print(result)          # 7.5
print(type(result))    # <class 'float'>

We added an int and a float. Python quietly changed 5 into 5.0 and gave us a float answer. It chose float because it can keep the decimal part. Converting to int would have thrown away the .5.

The same happens with bool: True is treated as 1 and False as 0, so True + 1 gives 2.

Important: Python will never automatically join a number and a text. That is exactly why "25" + 5 failed above. For that, we need explicit conversion.

2. Explicit Conversion (manual)

What is it?

Here you tell Python which type you want. Python gives us one simple function for each type:

FunctionConverts toExample
int()Whole numberint("25") → 25
float()Decimal numberfloat("3.14") → 3.14
str()Textstr(25) → "25"
bool()True / Falsebool(0) → False

Fixing our earlier error

# Step 1: the value is text
age = "25"

# Step 2: convert text into a number
age = int(age)

# Step 3: now math works
print(age + 5)          # 30
print(type(age))        # <class 'int'>

That's it — one line of conversion fixes the problem.

Converting a number into text

The same problem happens in the opposite direction. You cannot join a number directly to a sentence:

age = 25

print("Age: " + age)         # TypeError!
print("Age: " + str(age))    # Age: 25

Use str() to change the number into text first, and then the + sign will work.

3 Conversions That Confuse Beginners

1. Text with a decimal point → int()

int("25.5")     # ValueError: invalid literal for int() with base 10: '25.5'

int() cannot read a text that has a decimal point. First convert it to float, then to int:

int(float("25.5"))    # 25

Notice that the .5 is lost. int() does not round the number — it simply cuts off everything after the decimal point. So int(25.9) is 25, not 26.

2. Text that is not a number at all

int("abc")      # ValueError: invalid literal for int() with base 10: 'abc'

Python can only convert text that actually looks like a number. Words like "abc" or "twenty" will always give a ValueError.

3. bool() on text

print(bool(0))         # False
print(bool(1))         # True
print(bool(-7))        # True   — any number except 0 is True
print(bool(""))        # False  — empty text
print(bool("False"))   # True   — surprise!

The last line surprises almost everyone. bool("False") gives True! The reason is simple: Python does not read the meaning of the word. It only checks whether the text is empty or not. The text "False" has letters in it, so it is not empty, so the answer is True.

Simple rule: 0, empty text, and empty things are False. Everything else is True.

A Practical Example

Let's say a user types their age, and we want to tell them their age next year. The input() function always returns text, so we must convert it.

# Step 1: take input (arrives as text)
user_input = input("Enter your age: ")     # user types 30

# Step 2: convert text to a number
age = int(user_input)

# Step 3: do the math
next_year_age = age + 1

# Step 4: convert back to text to join with a sentence
print("Next year you will be " + str(next_year_age))
# Next year you will be 31

See the pattern? Convert in → Calculate → Convert out. If you remember this one pattern, most beginner type errors will disappear.

Quick Recap

SituationWhat to do
Check the type of a valueUse type()
Data is text, but you need to do mathConvert with int() or float()
Number needs to go inside a sentenceConvert with str()
Text has a decimal point, you want a whole numberUse int(float(...))
Text is not a number at all (like "abc")It cannot be converted — you get a ValueError
Checking True / False of textAny non-empty text is True, only "" is False

Getting comfortable with variables and type conversion early makes everything ahead — reading files, cleaning data, working with pandas — much easier. Most "strange errors" that beginners face come from a type mismatch like the ones we saw here.
