List Comprehensions in Python

What is a List Comprehension?

A list comprehension is a short way to create a list in Python, using a single line of code instead of a full loop. It takes an existing loop pattern and writes it in a compact, readable form.

A list comprehension builds a new list by applying an expression to every item of another sequence, optionally filtering some items out.

To understand it well, first look at the normal loop way, then see how the comprehension does the same thing.

The Normal Loop Way

Suppose we want a list of squares of numbers from 1 to 5.

squares = []
for n in range(1, 6):
    squares.append(n * n)

print(squares)

Output:

[1, 4, 9, 16, 25]

The Same Thing With a List Comprehension

squares = [n * n for n in range(1, 6)]
print(squares)

Output:

[1, 4, 9, 16, 25]

Both examples give the same result, but the comprehension does it in one line. It follows this pattern:

new_list = [expression for item in sequence]
  • expression is what you want to store for each item.
  • item is the variable name for each element, one at a time.
  • sequence is what you are looping over: a list, a string, a range, and so on.

Adding a Condition

List comprehensions can also filter items using an if at the end.

new_list = [expression for item in sequence if condition]

Example: keep only the even numbers from 1 to 10.

numbers = range(1, 11)
evens = [n for n in numbers if n % 2 == 0]
print(evens)

Output:

[2, 4, 6, 8, 10]

Here, the condition n % 2 == 0 checks whether a number is even. Only the numbers that pass the condition are added to the new list.

Normal Loop Version (for comparison)

numbers = range(1, 11)
evens = []
for n in numbers:
    if n % 2 == 0:
        evens.append(n)

print(evens)

The comprehension version does the same job in a single line and is easier to read once you are used to the pattern.

Using if...else Inside a Comprehension

You can also transform every item differently based on a condition, using if...else. The position of if...else is different here: it comes right after the expression, not at the end.

new_list = [value_if_true if condition else value_if_false for item in sequence]

Example: label each number as "Even" or "Odd".

numbers = [1, 2, 3, 4, 5]
labels = ["Even" if n % 2 == 0 else "Odd" for n in numbers]
print(labels)

Output:

['Odd', 'Even', 'Odd', 'Even', 'Odd']

Working With Strings

A list comprehension does not need to loop over numbers only. It can loop over the characters of a string, since a string is also a sequence in Python.

word = "python"
letters = [ch.upper() for ch in word]
print(letters)

Output:

['P', 'Y', 'T', 'H', 'O', 'N']

Working With a List of Words

words = ["data", "science", "ai"]
lengths = [len(w) for w in words]
print(lengths)

Output:

[4, 7, 2]

Nested Loops in a Comprehension

You can use more than one for inside a comprehension. This is useful when you need to combine items from two sequences.

pairs = [(x, y) for x in [1, 2] for y in ["a", "b"]]
print(pairs)

Output:

[(1, 'a'), (1, 'b'), (2, 'a'), (2, 'b')]

This is the same as writing two loops, one inside the other:

pairs = []
for x in [1, 2]:
    for y in ["a", "b"]:
        pairs.append((x, y))

Tip: Nested comprehensions are powerful, but they can also become hard to read. If a comprehension needs two or more for parts and a condition, it is often clearer to write it as a normal loop instead.

Dictionary and Set Comprehensions (A Quick Look)

The same idea also works for dictionaries and sets, using {} instead of [].

# Dictionary comprehension
squares_dict = {n: n * n for n in range(1, 5)}
print(squares_dict)

# Set comprehension
unique_lengths = {len(w) for w in ["data", "ai", "code", "ai"]}
print(unique_lengths)

Output:

{1: 1, 2: 4, 3: 9, 4: 16}
{2, 4}

We will cover dictionaries and sets in more detail in their own article. For now, just remember that comprehensions are not only for lists.

When Should You Use a List Comprehension?

  • Use it when the logic is short and easy to read in one line.
  • Avoid it when the logic has many steps or many conditions, since a normal loop will be clearer for you and for anyone reading your code later.
  • List comprehensions are usually a little faster than a normal loop with append(), but readability matters more than a small speed gain.

Practice Questions

  1. Write a list comprehension that creates a list of cubes of numbers from 1 to 5.
  2. Write a list comprehension that picks out only the vowels from the word "programming".
  3. Write a list comprehension that converts a list of temperatures in Celsius to Fahrenheit.
  4. Write a dictionary comprehension that maps each word in a list to its length.
