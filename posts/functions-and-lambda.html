Functions and lambda

Why This Topic Matters

So far every example we wrote ran once, top to bottom. A function lets you package a piece of code, give it a name, and run it again and again, with different inputs, whenever you need it. It is one of the biggest steps from writing small scripts to writing real programs.

By the end of this post you will know:

  1. How to define and call a function
  2. Parameters, default values, and returning a result
  3. Flexible arguments with *args and **kwargs
  4. Variable scope, what a function can and cannot see
  5. What a lambda is, and when it is genuinely useful

1. Defining and Calling a Function

1.1 What is a Function?

A function is a named, reusable block of code that runs only when you call it.

You have already used functions like print(), len() and int(). Now we will write our own.

Simple Example

def greet():
    print("Hello!")

greet()    # Hello!

def starts the definition, greet is the name, and the empty () means it takes no input. Nothing happens when you define the function, code inside it only runs when you call it with greet().

1.2 Parameters: Giving a Function Input

def greet2(name):
    print(f"Hello, {name}!")

greet2("Satyam")    # Hello, Satyam!

name here is a parameter, a placeholder for whatever value you pass in when you call the function. The value you actually pass, "Satyam", is called an argument.

1.3 return: Sending a Value Back

print() only shows a value on screen, it does not give the value back to your code. To get a result back, use return.

def add(a, b):
    return a + b

result = add(3, 5)
print(result)    # 8

As soon as Python hits return, it exits the function immediately and sends that value back to wherever the function was called. You can then store it in a variable, print it, or use it in another calculation.

def square(n):
    return n * n

print(square(4))          # 16
print(square(4) + 1)      # 17, the returned value can be used directly

2. Default Values and Keyword Arguments

2.1 Default Parameter Values

Give a parameter a default value, and the caller can skip it entirely:

def describe(name, age=18):
    print(f"{name} is {age} years old")

describe("A")          # A is 18 years old   (default used)
describe("B", 25)      # B is 25 years old   (default overridden)

A parameter with a default must come after the ones without a default. Python will not let you write def describe(age=18, name).

2.2 Calling with Keyword Arguments

You can also name the arguments when calling, so their order stops mattering:

def total(a, b, c=0, d=0):
    return a + b + c + d

print(total(1, 2))            # 3
print(total(1, 2, c=3))       # 6
print(total(a=1, b=2, d=4))   # 7

This is especially useful when a function has several optional parameters, since you only need to name the ones you are actually setting.

3. Flexible Arguments: *args and **kwargs

3.1 *args, Any Number of Positional Arguments

Use *args when you do not know in advance how many values will be passed in.

def add_all(*nums):
    return sum(nums)

print(add_all(1, 2, 3, 4))    # 10

Inside the function, nums becomes a tuple holding every value that was passed, however many there are.

3.2 **kwargs, Any Number of Named Arguments

def show(**info):
    for key, value in info.items():
        print(key, value)

show(name="A", age=25)
# name A
# age 25

info becomes a dictionary, so you can loop over it just like the dictionaries we covered earlier.

3.3 Forcing Keyword-Only Arguments

A single * on its own forces everything after it to be passed by name:

def make_full_name(first, *, last):
    return first + " " + last

print(make_full_name("A", last="B"))    # A B
print(make_full_name("A", "B"))         # TypeError

This is useful when a function has arguments that are easy to mix up by position, forcing a name makes the calling code clearer.

4. Variable Scope

4.1 Local vs Global

A variable created inside a function only exists inside that function. This is called its scope.
x = 10

def change():
    x = 20            # this is a NEW local variable, not the outer one
    print("inside", x)

change()               # inside 20
print("outside", x)    # outside 10, unchanged

The x inside change() is a completely separate variable from the x outside. This is intentional, it stops a function from accidentally breaking code elsewhere in your program.

4.2 The global Keyword

If you genuinely need to change a variable from outside the function, use global:

x = 10

def change2():
    global x
    x = 99

change2()
print(x)    # 99

Use this sparingly. Functions that quietly change variables outside themselves are harder to follow and to debug. Most of the time, returning a value and reassigning it is clearer.

5. lambda: a Small, Anonymous Function

5.1 What is it?

A lambda is a short function written in a single line, with no name and no def keyword.
square_l = lambda n: n * n
print(square_l(5))    # 25

add_l = lambda a, b: a + b
print(add_l(3, 4))    # 7

This does exactly the same job as:

def square_l(n):
    return n * n

A lambda always has an implicit return, you just write the expression, no return keyword needed.

5.2 Where lambda Actually Gets Used

Writing square_l = lambda n: n * n is possible, but a normal def is usually clearer for anything you will name and reuse. The real value of lambda is as a quick, throwaway function passed straight into another function.

With filter(), keep only matching items

nums = [1, 2, 3, 4, 5, 6]
evens = list(filter(lambda n: n % 2 == 0, nums))
print(evens)    # [2, 4, 6]

With map(), transform every item

squares = list(map(lambda n: n * n, nums))
print(squares)    # [1, 4, 9, 16, 25, 36]

With sort(), a custom sort order

people = [("A", 25), ("B", 20), ("C", 30)]
people.sort(key=lambda p: p[1])    # sort by age, the second item
print(people)    # [('B', 20), ('A', 25), ('C', 30)]

Here key=lambda p: p[1] tells .sort() which part of each item to compare. Without it, Python would try to sort the tuples directly.

With reduce(), combine everything into one value

from functools import reduce

total2 = reduce(lambda a, b: a + b, nums)
print(total2)    # 21

5.3 lambda vs def, When to Use Which

SituationUse
The function needs a name you will call again elsewheredef
The function has more than one line, or needs a loop or condition insidedef
You need it only once, as an argument to sort(), map() or filter()lambda
The whole function is a single simple expressionEither works, lambda if it stays inline

A normal function can also be passed around the same way a lambda can:

def is_even(n):
    return n % 2 == 0

print(list(filter(is_even, nums)))    # [2, 4, 6]

This is exactly the same idea as before, functions in Python are values too, you can pass them into other functions just like a number or a string.

6. Functions That Take Other Functions

Because functions are values, one function can accept another function as an argument. This is the same idea that makes map(), filter() and sort(key=...) work.

def apply_twice(f, x):
    return f(f(x))

result = apply_twice(lambda n: n + 3, 10)
print(result)    # 16, since 10 + 3 = 13, then 13 + 3 = 16

7. Practical Examples

Example 1: Safe Division

def divide(a, b):
    if b == 0:
        return None
    return a / b

print(divide(10, 2))    # 5.0
print(divide(10, 0))    # None

Returning None instead of letting the program crash lets the calling code decide what to do about a bad input.

Example 2: Sorting a List of Products by Price

products = [
    {"name": "Pen", "price": 10},
    {"name": "Bag", "price": 500},
    {"name": "Book", "price": 150}
]

products.sort(key=lambda p: p["price"])
for p in products:
    print(p["name"], p["price"])

# Pen 10
# Book 150
# Bag 500

Example 3: Filtering and Transforming Together

marks = [45, 60, 90, 30, 75, 55]

passed = list(filter(lambda m: m >= 40, marks))
scaled = list(map(lambda m: m + 5, passed))
print(scaled)    # [50, 65, 95, 80, 60]

8. A Common Trap: Mutable Default Arguments

This is one of the most surprising bugs for beginners. Never use a mutable value, like a list, as a default argument:

def add_item(item, lst=[]):
    lst.append(item)
    return lst

print(add_item("a"))    # ['a']
print(add_item("b"))    # ['a', 'b']  , NOT ['b'] as you might expect!

The default list is created only once, when the function is defined, and every call that does not pass its own list keeps reusing the same one. The fix is to default to None, and create a fresh list inside the function:

def add_item2(item, lst=None):
    if lst is None:
        lst = []
    lst.append(item)
    return lst

print(add_item2("a"))    # ['a']
print(add_item2("b"))    # ['b']

9. Common Mistakes

MistakeWhat happensFix
Forgetting return, using print() insteadFunction gives back NoneUse return if you need to use the result later
A default parameter placed before a non-default oneSyntaxErrorNon-default parameters must come first
Using a mutable default, like lst=[]The default is shared across callsDefault to None, create the value inside the function
Writing a multi-line lambdaSyntaxErrorUse def for anything beyond one expression
Trying to change an outer variable without globalA new local variable is created insteadUse global, or better, return the new value

Functions are what let you stop repeating yourself, and lambdas are simply a shorthand for the smallest, most disposable ones. Once you are comfortable with both, most of the pandas and scikit-learn code you will read later starts to make a lot more sense, since it leans on this exact same pattern everywhere.

Practice Questions

  1. What is the difference between a parameter and an argument?
  2. What does a function return if it has no return statement at all?
  3. Rewrite def cube(n): return n ** 3 as a lambda.
  4. Why is def f(items=[]) considered risky?
  5. What does *args become inside the function body?

Answers

  1. A parameter is the placeholder name in the function definition. An argument is the actual value you pass in when calling it.
  2. None
  3. cube = lambda n: n ** 3
  4. The default list is created once and shared across every call that does not pass its own list, so changes from one call leak into the next.
  5. A tuple containing every positional argument that was passed in.
