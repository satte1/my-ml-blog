File Handling: Reading and Writing CSV and Text Files

Why This Topic Matters

Until now, every value we used disappeared the moment our program stopped running. Real work needs data that survives, a list of students saved to disk, a CSV exported from a website, a log file your program writes to over time. That is what file handling is for.

By the end of this post you will know:

  1. How to open, read and write plain text files safely
  2. The different modes files can be opened in
  3. How to read and write CSV files, both by row and by column name
  4. How to check if a file exists, and handle a missing one without crashing
  5. How pandas makes CSV work even shorter, once you understand what it is doing underneath

1. Opening a File

1.1 The Safe Way: with open()

The with statement opens a file, lets you use it, and closes it automatically, even if an error happens.
with open("demo.txt", "w") as f:
    f.write("Hello, Python!\n")
    f.write("This is line two.\n")

open() takes two main things: the filename, and the mode, which tells Python what you plan to do with the file. "w" means write. Here f is a file object, your handle to the open file, and everything inside the with block can use it.

You could open a file without with, using f = open(...) and f.close(), but if an error happens before close() runs, the file is left open. with guarantees it gets closed, so it is always the better choice.

1.2 File Modes

ModeMeaning
"r"Read (default). Fails if the file does not exist.
"w"Write. Creates the file if missing, erases existing content.
"a"Append. Creates the file if missing, adds to the end without erasing.
"x"Create. Fails if the file already exists.

The mode you pick decides whether your old data survives. "w" wipes the file clean before writing, this is the mistake that costs beginners their data most often.

2. Reading a Text File

2.1 Reading the Whole File at Once

with open("demo.txt", "r") as f:
    content = f.read()

print(content)
# Hello, Python!
# This is line two.

.read() gives you the entire file as one single string.

2.2 Reading Line by Line

For a large file, reading everything at once can use a lot of memory. Loop over the file object directly instead, it reads one line at a time:

with open("demo.txt", "r") as f:
    for line in f:
        print(line.strip())

# Hello, Python!
# This is line two.

.strip() removes the newline character (\n) at the end of each line, along with any extra spaces. Without it, you would see an extra blank line after every print.

2.3 Reading All Lines into a List

with open("demo.txt", "r") as f:
    lines = f.readlines()

print(lines)
# ['Hello, Python!\n', 'This is line two.\n']

.readlines() gives you a list of lines, each one still carrying its trailing \n.

3. Writing and Appending

3.1 Writing (and Overwriting)

with open("demo.txt", "w") as f:
    f.write("New content only.\n")

Opening in "w" mode erases whatever was in the file before, even if you only write one line. If the file did not exist yet, it gets created.

3.2 Appending Without Losing Old Data

with open("demo.txt", "a") as f:
    f.write("Appended line.\n")

with open("demo.txt") as f:
    print(f.read())

# Hello, Python!
# This is line two.
# Appended line.

Use "a" whenever you want to keep adding to a file over time, a log file is the classic example.

4. Handling a Missing File Safely

Trying to read a file that does not exist raises an error:

with open("missing.txt") as f:
    pass
FileNotFoundError: [Errno 2] No such file or directory: 'missing.txt'

Wrap it in try / except so your program can respond instead of crashing:

try:
    with open("missing.txt") as f:
        data = f.read()
except FileNotFoundError:
    print("That file does not exist yet.")

You can also check first, using the os module:

import os

print(os.path.exists("demo.txt"))     # True
print(os.path.exists("nope.txt"))     # False

5. CSV Files

5.1 What is a CSV File?

CSV stands for Comma-Separated Values, a plain text file where each line is a row, and commas separate the columns.

A CSV file is just a text file with a specific pattern, so you could technically read it with open() and split each line on commas yourself. Python's built-in csv module does this properly for you, and also handles tricky cases like commas inside quoted text.

5.2 Writing a CSV File

import csv

rows = [
    ["name", "age", "city"],
    ["Satyam", 25, "Jaipur"],
    ["Anita", 30, "Delhi"]
]

with open("students.csv", "w", newline="") as f:
    writer = csv.writer(f)
    writer.writerows(rows)

The resulting file looks like this:

name,age,city
Satyam,25,Jaipur
Anita,30,Delhi

Always pass newline="" when opening a file for CSV writing. Without it, Windows can add extra blank lines between rows.

5.3 Reading a CSV File, Row by Row

with open("students.csv", newline="") as f:
    reader = csv.reader(f)
    for row in reader:
        print(row)

# ['name', 'age', 'city']
# ['Satyam', '25', 'Jaipur']
# ['Anita', '30', 'Delhi']

Notice that "25" comes back as text, not a number. Every value read from a CSV file is a string, you will need int() or float() if you plan to do maths with it, exactly like we covered in the type conversion post.

5.4 Reading a CSV File by Column Name

Working with numbered positions like row[0] and row[1] gets confusing fast. DictReader lets you use column names instead:

with open("students.csv", newline="") as f:
    reader = csv.DictReader(f)
    for row in reader:
        print(row)
        print(row["name"], row["age"])

# {'name': 'Satyam', 'age': '25', 'city': 'Jaipur'}
# Satyam 25
# {'name': 'Anita', 'age': '30', 'city': 'Delhi'}
# Anita 30

DictReader automatically uses the first row of the CSV as the keys, so each row comes back as a dictionary.

5.5 Writing a CSV File from a List of Dictionaries

students = [
    {"name": "Satyam", "age": 25, "city": "Jaipur"},
    {"name": "Anita", "age": 30, "city": "Delhi"}
]

with open("students2.csv", "w", newline="") as f:
    writer = csv.DictWriter(f, fieldnames=["name", "age", "city"])
    writer.writeheader()
    writer.writerows(students)

fieldnames tells the writer the column order, and .writeheader() writes that first row for you. This pairs naturally with the list-of-dicts shape from the collections post.

6. The Shortcut: CSV Files with pandas

Once your CSV files get bigger, or you want to analyse the data instead of just reading it, pandas does most of this in one line.

import pandas as pd

df = pd.read_csv("students.csv")
print(df)
#      name  age    city
# 0  Satyam   25  Jaipur
# 1   Anita   30   Delhi

print(df["age"].mean())    # 27.5

Notice that pandas read the age column as actual numbers, not text, and let us take an average straight away. Saving back to CSV is just as short:

df.to_csv("students_out.csv", index=False)

index=False stops pandas from adding its own row numbers as an extra column in the file. We are only introducing pandas briefly here, it deserves, and will get, a post of its own.

7. csv module vs pandas: Which One to Use

SituationUse
A small file, or a one-time script with no analysis neededthe built-in csv module
You want full control over reading each row yourselfthe built-in csv module
You need to filter, group, average, or otherwise analyse the datapandas
The file is large, and you want it loaded quickly into a table-like structurepandas

8. Practical Examples

Example 1: Saving User Input to a File

name = input("Enter your name: ")
feedback = input("Enter your feedback: ")

with open("feedback.txt", "a") as f:
    f.write(f"{name}: {feedback}\n")

print("Saved, thank you!")

"a" mode means every new run of the program adds another line, instead of erasing what earlier users wrote.

Example 2: Finding the Average Marks from a CSV

import csv

total = 0
count = 0

with open("students.csv", newline="") as f:
    reader = csv.DictReader(f)
    for row in reader:
        total += int(row["age"])
        count += 1

print(total / count)    # 27.5

Every value from DictReader is text, so int(row["age"]) is doing the same job we practised in the type conversion post, converting text into a number before doing maths on it.

Example 3: Checking Before You Read

import os

filename = "students.csv"

if os.path.exists(filename):
    with open(filename, newline="") as f:
        print(f.read())
else:
    print(f"{filename} not found, nothing to show.")

9. Common Mistakes

MistakeWhat happensFix
Opening in "w" mode when you meant to keep old dataThe file is silently erased firstUse "a" to append, "w" only when you want a clean file
Forgetting newline="" when writing CSV on WindowsExtra blank lines appear between rowsAlways pass newline="" to open() for CSV work
Doing maths directly on a value from csv.readerTypeError, since the value is textConvert with int() or float() first
Reading a file without checking it existsFileNotFoundErrorCheck with os.path.exists(), or wrap in try / except
Forgetting to close a file opened without withData may not be fully saved to diskAlways use with open(...) as f:

File handling is the bridge between your Python code and the outside world, saved results, exported data, logs, and every dataset you will load in machine learning starts as a file on disk somewhere. Getting comfortable with modes, safe reading, and the difference between csv and pandas makes everything from here easier.
